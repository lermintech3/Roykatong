# ลอยกระทงออนไลน์

เว็บลอยกระทงแบบโต้ตอบได้ ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

- ฉากแม่น้ำยามค่ำคืนวาดด้วย Canvas: จันทร์เต็มดวงและเงาบนผิวน้ำ ปรางค์และศาลาริมฝั่งเปิดไฟสีทอง โคมลอย และพลุ
- ประดิษฐ์กระทงเอง 4 แบบ (ใบตองพับกลีบ, ดอกบัวบาน, ขนมปังรักษ์ปลา, มาลัยมงคล) ดอกไม้ 5 ชนิด และเทียน 3 สี
- พิธีลอย: จุดเทียน จุดธูป ตั้งจิตอธิษฐาน แล้วกระทงจะลอยออกไปตามสายน้ำ
- แตะกระทงที่ลอยอยู่เพื่ออ่านคำอธิษฐาน
- เสียงบรรยากาศ (เสียงน้ำและระฆัง) สร้างด้วย Web Audio
- หน้าความหมายของลอยกระทง และวิธีลอยแบบรักษ์น้ำ

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages ที่ Settings → Pages → Branch `main` / root

## แม่น้ำร่วม

เมื่อเปิดผ่าน claude.ai กระทงของทุกคนจะลอยอยู่ในแม่น้ำเดียวกัน
เมื่อเปิดจากที่อื่น เช่น GitHub Pages หรือไฟล์ในเครื่อง หน้าเว็บจะทำงานแบบส่วนตัว
กระทงจะลอยบนหน้าจอของคนนั้นคนเดียว และจำไว้ในเบราว์เซอร์นั้น
